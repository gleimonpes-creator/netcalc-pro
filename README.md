# NetCalc Pro — Calculadora de Sub-redes IPv4, CIDR e VLSM

Aplicativo web e mobile-first para cálculo de redes IPv4, segmentação VLSM, gerenciamento de projetos locais e exportação de relatórios técnicos.

## Funcionalidades
- Cálculo completo de sub-redes IPv4 (Rede, Broadcast, Primeiro/Último Host, Máscara e Wildcard).
- Segmentação automática por quantidade de sub-redes ou hosts necessários (VLSM).
- Gerenciamento de projetos salvos localmente (criar, renomear, excluir e backup em JSON).
- Relatório técnico exportável em CSV, TXT e impressão/PDF.
- Tema claro e escuro adaptado para uso em dispositivos móveis.

## Acesso Rápido
Abra o arquivo `index.html` em qualquer navegador moderno ou acesse via GitHub Pages.
